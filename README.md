# Product Management System

ระบบจัดการสินค้า (Product Management API) แบบ Layered Architecture
พัฒนาด้วย Node.js (Express) และ SQLite

## 🚀 วิธีรันโปรแกรม
1. ติดตั้ง Library: `npm install`
2. รัน Server: `npm start`

## 📁 โครงสร้าง
- `src/presentation`: API Routes & Controllers
- `src/business`: Business Logic & Validation
- `src/data`: Database Access
